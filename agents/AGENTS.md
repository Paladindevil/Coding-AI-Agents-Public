# Project Instructions for GitHub Copilot

These instructions apply to GitHub Copilot when it works in this project. Replace them with your project's own rules.

## General

- Read the relevant code before changing it.
- Follow the existing style, naming, and folder layout of the project.
- Keep changes small and focused on the request.
- Use British English in comments and documentation.

## Safety

- Never commit secrets, keys, or `.env` files.
- Do not commit or push unless the user asks.

## Testing

- Run the project's tests after making changes and report the result.
